How to join

Four steps and you're in. It takes about 15 minutes, most of it waiting for downloads.

  1. 1

    Install the CurseForge app

    CurseForge is a free launcher that installs modpacks for you. Download it, install it and sign in with your Minecraft (Microsoft) account when it asks.

    Get CurseForge ▸
  2. 2

    Install All the Mods 10

    In CurseForge, search for All the Mods 10 and install it. Pick the same version as the server, otherwise you can't connect.

    Server version: ATM10 8.3 Minecraft 1.21.1 · NeoForge 21.1.259
    ATM10 on CurseForge ▸ All versions ▸
    Picking a version: on the modpack page in CurseForge, click the version dropdown next to Install and choose the server's version. ATM10 is big, so give it extra RAM in CurseForge settings (we recommend up to 10 GB max).
  3. 3

    Add the extra mods

    Our server runs a few mods on top of ATM10. You need all of them, at exactly these versions. Each button below opens the right file on CurseForge (or Modrinth).

    Quick way to add them all: download every file below, then in CurseForge open your ATM10 profile, click the ⋮ menu and choose Open Folder. Open the mods folder and drop all the downloaded .jar files in there. Don't rename them.
    Loading mods… For ATM10 · Minecraft 1.21.1 · NeoForge
    Simple Voice Chat: once you're in game, press V to open the voice chat settings and pick your microphone. Talk with push-to-talk (default Caps Lock) to players near you.
  4. 4

    Add the server and connect

    1. Press Play on your ATM10 profile in CurseForge and wait for the game to load (the first start takes a while).
    2. Click Multiplayer, then Add Server.
    3. Paste the address below into Server Address, click Done and join.
    Server address 82.24.111.62:25565
    Stuck? Ask in our Discord. A "mod mismatch" error usually means a missing extra mod or the wrong ATM10 version.
